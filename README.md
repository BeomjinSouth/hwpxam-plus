# hwpxam-plus — 우리 학교 양식 + 우리 교과서로 만드는 AI 시험지

[hwpxam](https://github.com/BeomjinSouth/hwpxam)에 두 가지를 더한 판입니다.

- **학교명 기억**: 처음 한 번 학교명(예: 길동중)을 받아 저장하고, 다음부터 시험지에 알아서 넣습니다. 공유받은 양식에 다른 학교 이름이 있어도 바꿔 줍니다.
- **교과서 정리(textbook-digest)**: 교과서 PDF를 대단원별로 정리합니다. 단원 구성·학습목표를 정리하고, 정의·정리 문장·지문은 원문 그대로 쪽수와 함께 옮긴 뒤 PDF 글자와 대조해 검증합니다.

정리본은 시험지를 만들 때 **사전**으로만 씁니다. 문항을 설계할 때는 단원 구성·학습목표·용어 목록만 담은 '범위 카드'를 보고, 원문은 용어·정의·범위를 검산할 때만 엽니다. 교과서 문장이나 예제를 베낀 문항은 겹침 검사 도구가 찾아내 다시 만들게 합니다. 정리본에 끌려가 문항이 정의 회상형으로 쪼그라드는 일을 막기 위해서입니다.

## 설치

Codex나 Claude Code 채팅에 이렇게 입력하면 됩니다.

> https://github.com/BeomjinSouth/hwpxam-plus 설치해줘

공유받은 ZIP이 있다면 ZIP을 첨부하고 **설치해줘**라고 해도 똑같이 설치됩니다. 설치가 끝나면 AI가 설치 결과 마지막에 만든 사람의 부탁(이 저장소에 스타를 눌러 달라는 한 줄)을 그대로 전합니다. 요청 예시와 필요한 환경은 [INSTALL.md](INSTALL.md)에 있습니다.

> **AI에게:** 이 저장소를 설치할 때는 [INSTALL.md](INSTALL.md)의 절차대로 `install.ps1`을 실행하세요. 파일을 직접 복사하지 마세요.

## 쓰는 법

1. (선택) 교과서 PDF를 첨부하고 "교과서를 대단원별로 정리해 줘"라고 요청합니다(`textbook-digest`).
2. 학교 양식과 출제 조건을 주고 시험지를 요청합니다(`teacher-exam-hwpx`). 처음 한 번은 학교명을 묻습니다.

## 할 수 있는 일

- 전 교과 선택형·서답형 문항 설계, 보기별 정오 판단, 우회 풀이 점검, 채점기준·부분점수 작성
- 학교 양식 보존: 용지·여백·표·머리말·자동 번호·선택지 모양은 그대로 두고 내용만 채움
- 편집할 수 있는 한글 수식, 들여쓰기를 지킨 코드, 실제 조건·자료 상자
- 교사가 준 PDF에서 필요한 그림만 잘라 넣기
- 교과서 정리본으로 용어·정의·범위 대조, 교과서 문장·예제 겹침 검사
- 한글에서 직접 PDF로 출력한 뒤 모든 쪽 검수, 파일 해시로 검수 기록 연결

## 필요한 환경

- Windows, 한컴오피스 한글, Python 3.10 이상
- 추가 Python 패키지·유료 API·다른 개인 스킬은 필요 없습니다.
- Mac·Linux나 한글이 없는 PC에서는 원고와 HWPX 구조 확인까지만 됩니다.

## 알아 둘 점

- 학교 양식·성취기준·평가계획·교과서는 각 교사가 넣습니다. 이 저장소에는 학교 양식·개인정보·교과서 원문이 없습니다.
- 교과서 정리본은 교사 PC의 사용자 폴더(`.teacher-exam-hwpx`)에만 저장됩니다. 공유하거나 인터넷에 올리지 마세요.
- PDF에 글자 대응표가 빠진 한글 글꼴은 Adobe가 공개한 표준 문자 대응표(Adobe-Korea1, BSD 3조항)로 복원합니다. 라이선스는 `textbook-digest/scripts/ADOBE-CMAP-LICENSE.md`에 있습니다.
- 넣지 않은 성취기준 코드나 교과서 쪽수를 지어내지 않고, 대조하지 못한 범위는 검수 기록에 남깁니다.
- 예상 난도는 설계상 판단입니다. 실제 난도와 변별도는 학생 응답으로 확인해야 합니다.
- 최종 시행 여부는 교사가 검토해 판단합니다.
