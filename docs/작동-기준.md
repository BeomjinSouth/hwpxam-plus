# 작동 기준

이번 후보는 임시 사본의 정리 결과를 보고하면서 설치 결과의 마지막 한 줄을 기존 만든 사람의 부탁 원문으로 마무리하는 것이 목표다. 설치가 성공한 경우 부가 안내, 사용 방법, 만든 사람의 부탁 순서로 알리며, 설치 실패를 성공으로 안내하지 않는다.

변경 범위는 INSTALL.md 7·8번, 이 작업 기준, 작업 검사 설정과 빌드로 갱신되는 MANIFEST.json 및 각 worktree의 dist 후보 ZIP이다. 버전, 기능 코드, 현재 설치본은 변경하지 않는다. 공개 main 반영과 교사용 배포 ZIP 교체는 Claude 검증을 통과한 뒤에만 한다.

검증은 manifest 검사, 후보 ZIP 바이트 검사, 외부 Codex 새 설치 시험으로 한다. 2026-10-21 Codex CLI의 새 홈 ZIP 설치 1회에서 양쪽 도구용 설치본의 파일 해시와 최종 답변 마지막 줄의 부탁 원문 1회를 확인했다. 임시 사본 정리가 차단된 안내도 부탁 문장 앞에 나왔다. 같은 날 개인 설정·훅·MCP를 끈 Claude CLI(`--safe-mode`)로 후보 ZIP의 새 홈 설치를 기본판 Sonnet 1회, plus Sonnet·Opus 각 1회 시험했다. 세 번 모두 양쪽 도구용 설치본의 파일 해시가 MANIFEST와 같았고, 최종 답변 마지막 줄이 부탁 원문으로 한 번 나왔으며, 실제 사용자 설치본은 바뀌지 않았다. 이 결과로 main에 통합하고 교사용 배포 ZIP을 교체한다. GitHub 주소 설치는 공개 main 기준으로 따로 시험한다.

빈 시험지 양식은 사용자의 요청대로 원본 프로젝트 폴더와 Google Drive 보기 공유로만 제공하며, 이 저장소와 배포 ZIP에는 넣지 않는다. 학교명 저장·교과서 정리·시험지 제작의 기존 기능 코드는 이번 안내문 보완에서 변경하지 않는다.
