# 작동 기준

이번 작업의 목표는 같은 이름의 스킬이 이미 다른 내용으로 설치된 PC에서도 AI가 교사의 요청 없이 기존 설치본을 바꾸지 않게 하는 것이다. 설치 도구가 기존본을 보존(PRESERVED_DIFFERENT)하면 AI는 차이와 보존 위치를 알리고 업그레이드 여부를 묻는다. 교사가 바꾸겠다고 답했을 때만 -Upgrade로 다시 실행한다. 설치 답변은 부가 안내, 사용 방법, 만든 사람의 부탁 순서로 끝난다.

변경 범위는 INSTALL.md 5번의 보존 안내 문장, 이 작업 기준, 빌드로 갱신되는 MANIFEST.json과 dist ZIP이다. install.ps1, 스킬 코드, 버전은 바꾸지 않는다. 교사용 배포 ZIP 교체와 main 반영은 아래 검증을 통과한 뒤에만 한다.

검증은 manifest 검사와 설치 테스트 13개, 그리고 실제 AI 설치 시험으로 한다. AI 시험은 모두 시험 폴더 안의 새 교사 홈에서 하며 실제 사용자 설치본은 전후 해시로 확인한다. 새 홈 설치에서는 설치본 해시와 마지막 줄 원문 1회를, 다른 판이 미리 설치된 홈에서는 기존본이 그대로인지, 백업이 생기지 않았는지, 마지막 줄 원문 1회인지를 본다.
