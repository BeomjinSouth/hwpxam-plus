# 작동 기준

이번 후보는 임시 사본의 정리 결과를 보고하면서 설치 결과의 마지막 한 줄을 기존 만든 사람의 부탁 원문으로 마무리하는 것이 목표다. 설치가 성공한 경우 부가 안내, 사용 방법, 만든 사람의 부탁 순서로 알리며, 설치 실패를 성공으로 안내하지 않는다.

변경 범위는 INSTALL.md 7·8번, 이 작업 기준, 작업 검사 설정과 빌드로 갱신되는 MANIFEST.json 및 각 worktree의 dist 후보 ZIP이다. 버전, 기능 코드, 현재 설치본과 공개 main은 변경하지 않는다. 공개 배포 루트 ZIP도 교체하지 않는다.

검증은 manifest 검사, 후보 ZIP 바이트 검사, 외부 Codex 새 설치 시험으로 한다. 2026-10-21 Codex CLI의 새 홈 ZIP 설치 1회에서 양쪽 도구용 설치본의 파일 해시와 최종 답변 마지막 줄의 부탁 원문 1회를 확인했다. 임시 사본 정리가 차단된 안내도 부탁 문장 앞에 나왔다. Claude는 미검증이다. 사용자의 추가 요청에 따라 검증한 후보 브랜치는 GitHub에 푸시해 보존한다. Claude 검증 전에는 main에 병합하거나 교사용 배포 ZIP을 교체하지 않는다.

빈 시험지 양식은 사용자의 요청대로 원본 프로젝트 폴더와 Google Drive 보기 공유로만 제공하며, 이 저장소와 배포 ZIP에는 넣지 않는다. 학교명 저장·교과서 정리·시험지 제작의 기존 기능 코드는 이번 안내문 보완에서 변경하지 않는다.
