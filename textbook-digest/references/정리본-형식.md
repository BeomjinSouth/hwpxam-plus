# 정리본 형식

정리본 폴더는 `textbooks/<id>/`이다. 도구가 만드는 파일과 AI가 쓰는 파일이 나뉜다.

| 파일 | 만드는 쪽 | 내용 |
|---|---|---|
| `meta.json` | init | 교과·학년·출판사·저자·교육과정, PDF 경로·해시·쪽수, `page_offset` |
| `pages.jsonl` | extract | PDF 쪽별 글자(쪽 번호는 PDF 기준, 첫 쪽 1) |
| `extract.json` | extract | 추출 요약(글자 없는 쪽, 읽지 못한 글자 비율) |
| `toc.json` | AI | 대단원·중단원·소단원과 쪽 범위 |
| `units/<번호>-<제목>/원문.json` | AI | 대단원 원문 항목 |
| `units/<번호>-<제목>/검증.json` | verify | 항목별 검증 결과 |
| `units/<번호>-<제목>/원문.md`, `범위카드.md` | render | 사람이 읽는 문서 |

## toc.json

```json
{
  "textbook_id": "수학2-홍길동-2015",
  "units": [
    {
      "order": 3,
      "no": "Ⅲ",
      "title": "일차함수",
      "pdf_pages": [101, 140],
      "sections": [
        {"no": "1", "title": "일차함수와 그 그래프", "pdf_pages": [102, 121]},
        {"no": "2", "title": "일차함수와 일차방정식의 관계", "pdf_pages": [122, 136]}
      ]
    }
  ]
}
```

`order`는 1부터 시작하는 대단원 순서이며 폴더 번호(`03`)가 된다. `pdf_pages`는 시작·끝 PDF 쪽(끝 포함)이다. 제목은 차례에 인쇄된 그대로 쓴다.

## 원문.json

```json
{
  "textbook_id": "수학2-홍길동-2015",
  "unit_order": 3,
  "entries": [
    {"id": "U03-001", "kind": "objective", "section": "1", "text": "학습목표 문장", "pdf_page": 102, "source": "text"},
    {"id": "U03-002", "kind": "definition", "section": "1", "label": "일차함수", "text": "정의 문장 원문", "pdf_page": 104, "source": "text"},
    {"id": "U03-003", "kind": "property", "section": "1", "label": "기울기", "text": "y=ax+b의 그래프에서 …", "pdf_page": 110, "source": "visual"},
    {"id": "U03-004", "kind": "passage", "section": "2", "label": "지문 제목", "text": "지문 원문", "pdf_pages": [124, 125], "source": "text"},
    {"id": "U03-005", "kind": "example", "section": "1", "label": "예제 2", "task": "두 점을 지나는 직선의 기울기 구하기", "text": "(선택) 예제 원문", "pdf_page": 111, "source": "text"},
    {"id": "U03-006", "kind": "scope_note", "section": "", "text": "그래프의 평행이동은 y축 방향만 다룬다.", "source": "judgment"}
  ]
}
```

### kind

| kind | 담는 것 | source |
|---|---|---|
| `objective` | 학습목표 | text 또는 visual |
| `definition` | 정의(굵은 용어, '~라고 한다' 문장) | text 또는 visual |
| `summary` | 개념 정리·핵심 정리·단원 마무리의 정리 문장 | text 또는 visual |
| `property` | 성질·법칙·공식·정리 | text 또는 visual |
| `notation` | 기호·표기 약속, 용어 사용법 | text 또는 visual |
| `passage` | 지문·읽기 자료 원문 | text 또는 visual |
| `example` | 예제·문제·탐구 문제(`task` 필수, `text` 선택) | text 또는 visual |
| `activity` | 탐구·활동 제목과 목적 | text 또는 visual |
| `scope_note` | 다루는 것·다루지 않는 것에 대한 판단 | judgment만 |

### 규칙

- `id`는 정리본 안에서 겹치지 않는다.
- `text` 항목은 `pdf_page`(한 쪽) 또는 `pdf_pages`(여러 쪽, 시작·끝)가 꼭 있어야 하고, 그 쪽의 PDF 글자 안에 공백만 다르게 들어 있어야 한다.
- `visual` 항목도 쪽 정보는 꼭 넣는다. 눈으로 옮긴 이유를 `note`에 짧게 적는다(예: "수식 글꼴이 글자 레이어에 없음").
- `judgment` 항목은 쪽 정보가 없어도 된다. 교과서 문장처럼 따옴표로 꾸미지 않는다.
- 한 문장을 여러 항목으로 쪼개거나, 여러 문장을 이어 하나로 만들지 않는다. 교과서가 한 상자에 둔 정리 문장 묶음은 한 항목으로 둘 수 있다.
- 책 쪽수는 `meta.json`의 `page_offset`으로 계산한다. 특정 쪽만 어긋나면 그 항목에 `book_page`를 직접 적는다.
