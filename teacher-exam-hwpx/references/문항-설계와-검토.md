# 문항 제작 요령과 검토

## 평가할 판단에서 시작한다

교과·학년·허용 지식·자료의 범위와 교사의 평가목표를 먼저 맞춘다. 성취기준은 제공된 원문 또는 확인한 공식 자료에서 인용한다. 확인하지 못했다면 내용 범위만 잠정 설정하고 교육과정 대조 미완료라고 쓴다.

문항마다 ‘학생이 무엇을 근거로 어떤 결론을 내리는가’를 한 문장으로 적는다. 예를 들어 국어에서는 두 자료의 근거가 결론을 지지하는 정도를 비교하고, 사회에서는 서로 다른 입장에서 같은 자료를 해석하며, 과학에서는 통제 변인을 구별해 실험 결과의 해석 범위를 판단할 수 있다. 이는 설계 예시이며 실제 성취기준의 대체 문구가 아니다.

중상 이상 문항에서는 같은 목표를 평가하는 추론 구조 두 개를 짧게 비교한다. 다른 상황·자료·관계를 구성하고, 채택한 안에 학생이 연결해야 할 정보와 예상 오개념을 적는다. 기초 문항은 그 평가 역할을 유지한다. 큰 수·전문 용어·불필요한 장문·단순 작업량을 난도의 근거로 쓰지 않는다.

기출이나 교과서 자료를 참고하면 실제 자료의 조건·추론과 확인한 범위를 읽는다. 출처 이름만 붙이거나 소재·수치·인명만 바꿔 신작이라고 하지 않는다. 창작 지문은 창작이라고 밝힌다. 원문 인용과 재구성을 구분하고 원문의 논지·화자·시대·조건을 바꾸지 않는다.

## 문항별로 남길 기록

| 항목 | 확인할 내용 |
|---|---|
| 평가목표 | 실제로 필요한 교과 개념·읽기·추론과 허용 범위 |
| 근거 | 지문·자료의 어느 부분이 답을 지지하는지, 자료 밖 지식이 필요한지 |
| 가장 짧은 풀이 | 생략할 수 없는 판단과 타당한 대안 풀이 |
| 보기별 판정 | 정답 조건에 해당하는지와 구체적 근거·반례 |
| 오답 설계 | 각 오답이 진단하는 오개념·오독·인과 혼동·범위 과장 |
| 난도 | 실제 판단의 종류·연결·친숙도. 시행 전에는 예상 난도 |
| 채점 | 부분점수·인정 표현·오류 처리·대체 답안 |
| 근거 범위 | 확인한 자료와 쪽·절, 창작 여부, 교육과정 대조 상태 |

정답은 모든 조건을 만족하고, 다른 답이 성립하지 않는지도 확인한다. ‘옳지 않은 것’에서 참인 문장을 정답이라고 처리하지 않는다. 선택지의 사실성·논리성이 겹치거나 포함 관계가 있으면 질문이 답을 유일하게 정하는지 다시 판단한다. 합리적으로 가능한 독해를 오답 처리하지 않는다.

오답은 정답과 문법·길이·구체성·개념 수준을 맞추되 의미를 억지로 늘리지 않는다. 보기 길이만으로 답이 드러나거나 정답에만 세밀한 조건이 붙는지 확인한다. 내용상 순서가 있으면 그 순서를 우선하고, 정답 위치를 맞추려고 의미를 바꾸지 않는다.

## 목표 판단을 피하는 우회로

각 항목은 `found`(발견), `blocked`(시도한 범위에서 미발견), `not_applicable`(해당 없음과 이유)로 적는다. `blocked`는 모든 우회로가 없다는 증명이 아니다.

1. **선택지 단서**: 길이·어휘 반복·문법 호응·극단어·상하위 개념만으로 하나가 남는가? 선택형에서는 생략하지 않는다.
2. **부분 근거**: 자료 일부만 읽거나 보기를 역으로 대입해 핵심 판단을 피하는가? 같은 목표를 평가하는 대안이면 인정한다.
3. **특수 사례·상식**: 의도한 개념 대신 익숙한 사례·일반 상식·표면적 수치만으로 답이 나오는가?
4. **발판 누출**: 물음·보기·소제목·자료 설명이 필요한 중간 결론을 알려 주는가?
5. **장식 조건**: 자료나 조건을 하나씩 지워도 풀이·답이 그대로인가? 답을 하나로 만들기 위해 부자연스러운 예외를 덧붙였는가?
6. **익숙한 정형**: 외운 문구나 정형 문항의 답을 재현하면 끝나는가? 새로운 자료에서 실제 판단이 남는가?
7. **범위 밖 지식**: 배우지 않은 용어·시대 배경·전문 지식을 알아야만 풀리거나 그것으로 목표를 건너뛰는가?

선택형은 지문·자료·발문을 가리고 선택지만 읽는 점검을 실제로 한 번 수행한다. 그때 남는 정답 후보와 표현 단서를 적은 뒤 자료를 공개한 풀이와 비교한다. 정답만 유보하거나 오답만 강하게 단정하는 등 표현의 강도로 후보가 좁혀지면, 보기의 판단 강도를 맞추고 자료 해석이 필요한 오답으로 고친다. 단서가 없다고 선언하는 대신 가린 상태에서 시도한 판단을 기록한다.

목표 판단이 사라지는 우회로가 있으면 수정한다. 동일한 평가목표를 확인하는 정당한 대안은 제외하지 않는다. 수정 후 학생용만 다시 풀고 기존 검토를 그대로 붙이지 않는다.

## 서답형과 시험 전체

확정 전에는 루브릭의 각 점수 요소를 학생용 발문·조건의 구체적인 구절에 역으로 연결한다. 시간과 장소처럼 서로 다른 이유에 각각 점수를 배정하면 학생용에도 각각 답하라는 요구를 명시한다. 학생에게 요구하지 않은 요소를 숨은 필수 배점으로 삼지 않는다. 단어 나열·일부 답안의 점수는 항목명과 점수를 하나씩 적어 합계가 모호하지 않게 한다. 이 역대조는 검토 원고의 `rubric_alignment`에 남기고 최종 인쇄 내용에서도 다시 확인한다.

서답형은 답뿐 아니라 근거와 배점, 인정할 다른 표현, 부분 답안 조합, 답만 썼을 때의 점수, 같은 오류의 반복 처리, 과잉·모순 답안 처리를 실제 교사용 파일에 넣는다. 키워드가 있어도 논리가 틀린 경우와 표현만 다른 동치 답안을 구별한다. 채점 항목 합계는 문항 배점과 맞춘다.

발문이 요구하지 않은 조사 범위나 추가 설명에 숨은 필수 배점을 두지 않는다. 문법 오류나 시간·장소 누락처럼 하나의 결함을 세부 요소와 문장 완결 항목에서 중복 감점하지 않는다. 모범답안과 형식이 달라도 교과상 타당한 표현·관찰 방법·알고리즘이면 인정 조건을 구체적으로 적는다.

전체에서는 내용·사고 유형·소재·추론 구조가 반복되는지, 한 문항의 지문·보기·해설 단서가 다른 문항의 답을 노출하는지 확인한다. 같은 지문을 공유하는 문항은 연결의 교육적 목적과 답 독립성을 함께 본다. 시험 시간에는 읽기·판단·쓰기 시간을 반영한다.

별도 검토자는 학생용과 평가 범위만 먼저 읽어 답과 근거를 기록한다. 이후 교사용과 대조하여 불일치 원인을 원문에서 찾는다. 제작자는 별도 검토자의 답과 PASS를 대신 작성하지 않는다. 별도 검토가 있어도 자료의 실제 내용·반례·교육과정 적합성을 다시 살핀다.

## 중상 난도는 어떻게 만들고 탈락시키는가

‘자료가 두 개다’, ‘계산을 두 번 한다’, ‘코드가 길다’만으로 중상 난도가 되지는 않는다. 중상은 가르친 범위 안에서 필요한 판단을 연결·전이하거나, 학생이 반례·비교 방법·근거를 구성해야 하는 문항으로 설계한다. 이 단계에서는 예상 난도다. 실제 난도와 변별도는 학생 응답으로 확인한다.

먼저 같은 목표의 설계안 두 개를 비교한다. 하나는 정의나 유형을 재현하면 풀리는 안, 다른 하나는 새로운 자료에서 관계를 판단하는 안으로 두어 차이를 확인한다. 최종 기록에는 형식 이름 대신 어떤 조건과 자료가 어느 판단에 쓰였는지 적는다. 익숙한 공식을 쓰더라도 미지 조건을 역산한 뒤 바뀐 조건에 적용하는 과정이 남는지 살핀다.

| 교과 | 사고를 연결하는 설계 예 | 쉬운 문항으로 돌아가는 경우 |
|---|---|---|
| 국어 | 관찰 사실과 양립하는 반례를 만들고, 두 설명을 구별할 자료와 기사 표현을 제안한다. | ‘단정하지 않는다’는 보기만 정교하고 나머지는 ‘모두·항상’으로 틀리게 만든다. |
| 영어 | 자격별 원래 계획, 장소 변경, 개인의 가능 시간을 연결해 계획과 이유를 영어로 구성한다. | 변경 공지를 빼도 원래 계획만으로 답이 같거나, 선택지를 개인의 귀가 시간 하나로 지울 수 있다. |
| 사회 | 동시 행사와 집단의 기존 차이를 구별할 비교 조사를 설계하고, 필요한 통제 조건을 고른다. | ‘추가 조사한다’라는 일반론만으로 만점이거나 정답만 중간 타협안이다. |
| 과학 | 관측한 열평형으로 미지 질량을 구한 뒤 새로운 혼합의 평형을 예측하고 관계를 설명한다. | 모든 값을 공식에 한 번 넣으면 끝나거나, 그림을 보지 않아도 답이 남는다. |
| 역사 | 서로 다른 기록의 취재·전재 계통을 추적하고 사건의 발생, 행위자, 의도를 나누어 결론을 수정한다. | ‘원본’이라고 적힌 자료 두 개만 고르면 끝나거나 정답만 판단을 유보한다. |
| 정보 | 실패 입력을 스스로 만들고 상태 변화를 설명한 뒤 원본·순서·중복을 보존하는 알고리즘으로 고친다. | 반복을 짧게 한 번 따라가면 끝나거나 유일하게 반복 모양이 다른 입력을 찾으면 된다. |

### 실제로 지워 보고 다시 푼다

독립 검토자에게 자료 하나를 가리거나, 물음과 보기만 먼저 읽는 시도를 맡긴다. 발견한 짧은 풀이가 목표 개념을 확인하는 정당한 대안이면 인정한다. 예를 들어 각 물질의 질량과 온도 상승의 역비례로 풀었다면, 굳이 두 물질 사이의 비열을 먼저 구하게 강제하지 않는다. 그 추론이 필수가 아니었다면 난도 근거에서 뺀다.

목표 판단이 사라지는 경우에는 보기를 보완하거나 문항을 탈락시킨다. 중상 목표를 만족하지 못했지만 중 수준의 개념·자료 연결을 확인하는 데 타당하면 **보조 문항으로 낮추고** 그 이유를 기록할 수 있다. 처음 요구한 중상 문항 수를 그런 보조 문항으로 채우지는 않는다. `found`를 발견해 놓고 `blocked`로 덮어쓰지 않는다.

검사기는 `found`를 원칙적으로 미해결로 처리한다. 중 수준 보조로 재분류한 경우에만 해당 문항의 `assessment_role: support`와 검사 기록의 `resolution: {decision: reclassified, new_level: 중, reason: 실제 이유}`를 함께 남길 수 있다. 이는 중상 난도 통과가 아니라 범위를 낮춘 판단이다.

### 채점은 대안 답안으로 시험한다

모범답안과 다른 타당한 답을 최소 하나 실제로 써서 점수를 매긴다. 학생이 구성한 반례가 달라지면 그 반례를 구별하는 적합한 조사 자료도 달라진다. 모든 답안에 하나의 자료 세트나 특정 알고리즘을 강제하지 않는다. 같은 원리를 200g과 0.2kg처럼 동치 단위로 표현한 답도 인정한다.

이어풀기를 허용한다면 앞의 단순 계산 실수 값을 일관되게 사용해 이후의 올바른 식·계산을 완성한 경우의 점수를 정한다. 선행 오류를 뒤 단계에서 다시 감점하지 않는 원칙과 최종값 점수 규칙을 서로 맞춘다. 0을 포함해야 하는 필터에서 0만 빠뜨린 경우처럼 자주 나올 경계 답안의 부분점수도 미리 정한다.

## 함께 참고할 공개 자료

[워털루대학교 교수학습센터의 선다형 문항 제작 안내](https://uwaterloo.ca/centre-for-teaching-excellence/catalogs/tip-sheets/designing-multiple-choice-questions)는 익숙한 용어, 완결된 발문, 그럴듯한 오답, 유일한 최선 답, 문법·길이·극단어·어휘 반복 단서 점검을 설명한다. 이 공통 유의사항을 한국 학교 문항에 맞게 짧게 재구성했다. 위 교과별 설계·탈락 사례와 채점 보완은 이 공유 스킬의 실제 검증에서 정리한 내용이며, 해당 대학의 교과별 난도 보증이나 한국 성취기준을 뜻하지 않는다. 원문을 통째로 묶지 않으며 링크에 접속하지 않아도 이 문서로 작업할 수 있다.
