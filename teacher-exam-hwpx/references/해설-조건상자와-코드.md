# 교사용 해설과 조건·코드 상자

## 교사에게 필요한 문서

교사가 준 교사용 양식이 있으면 그 양식을 복제한다. 별도 해설 양식이 없고 시험지와 비슷한 형식을 요청받으면 시험지의 용지·여백·제목란·다단·본문 글꼴을 재사용한다. 학생용 표지의 수험생 정보·시험 시작 안내·답안지 기입 안내는 해설에 옮기지 않는다. 이 경우 교사용 사본을 먼저 만들고 실제 한글에서 무편집 저장한 기준본으로 검증한다. 학생용 양식에는 같은 삭제를 적용하지 않는다.

선택형은 실제 문항 번호와 정답 선택지 번호, 해설, 선택지별 풀이를 구분한다. 논술형은 실제 문항 번호, 예시 답안, 평가 요소별 배점·인정 근거, 필요한 대안 답안과 부분점수 처리로 구성한다. 같은 풀이를 설계 추론과 예시 답안으로 두 번 인쇄하지 않는다. 데이터 키 MC1·E1, 검토 상태, 예상 난도 분류와 제작 경로를 해설 제목이나 본문에 찍지 않는다.

채점에 필요한 예외와 동치 답안은 남긴다. 모든 문항에 똑같이 반복되는 채점 일반론은 짧게 한 번만 적는다. 코드 예시는 한 줄에 세미콜론으로 이어 쓰지 않고 실행 가능한 줄·공백으로 제시한다. 실패 입력과 실행 결과를 구별한다.

## 인쇄물 밖에 남길 기록

PDF 쪽수·발췌 위치·해시·원고 상태·창작 검증·중상 예상·설치 경로 등 제작 정보는 별도 검수 기록에 둔다. 시험지에는 문제를 풀 때 필요한 내용과 교사의 지정 문구만 넣는다. 출처를 시험지 안에 표시하라는 요청이나 원문 이용 조건이 있으면 필요한 출처 표시는 유지한다. 그림 밖의 필수 조건을 지우지 않는다.

## 원본 조건 상자 복제

여러 작성 조건은 발문에 길게 이어 쓰지 않고 원본의 조건 상자 안에 번호별로 넣는다. 제시 자료·코드와 작성 조건을 구별한다. 조건을 옮길 때 요구 개수·대상·허용 범위·단위·배점을 바꾸지 않고 발문과 상자에 중복하지 않는다.

`assets/condition-box.xml`에는 승인된 참고 원안지에서 문항·학교·개인 정보를 제거한 상자의 4행·3열 구조, 테두리·제목 공간·안쪽 여백만 들어 있다. 교사가 준 양식의 상자가 있으면 그 상자 구조를 우선 추출하여 `body.box_profile`의 절대 경로와 SHA-256으로 지정한다. 글자 선으로 흉내 내거나 다른 학교의 표지를 붙이지 않는다. 참고 상자를 사용할 때에도 현재 단 폭에 맞는지 확인한다. 새 상자의 높이는 내용에 맞춰 늘릴 수 있다.

코드 A·B, 제시 알고리즘, 잘못된 코드와 수정 코드도 상자에 넣는다. 한 줄은 한 문단이며 공백·연산자·문자를 보존한다. 제목만 따로 남거나 상자를 넘어서 줄이 잘리지 않도록 최종 PDF를 본다. 제목이 두 줄로 갈리면 제목 공간만 조정하고 본문·전체 상자 폭은 보존한다.

## 실행 명세

기존의 평평한 `body.blocks`에 연속한 `box_id`를 붙이고 `body.boxes`에 같은 ID의 제목을 지정한다. 같은 ID를 떨어진 위치에 두 번 쓰지 않는다. 상자 안 문단에는 단·쪽 나눔을 넣지 않는다. 코드 줄에는 `code: true`도 붙인다. 일반 조건 문단은 테두리 없는 기존 본문 스타일을 써서 이중 테두리를 만들지 않는다.

```json
{
  "body": {
    "anchor": "실제 본문 표시자",
    "boxes": {"requirements":{"caption":"조건"},"code_a":{"caption":"코드 A","caption_width_mm":24}},
    "blocks": [
      {"style_id":0,"text":"1. 두 결정의 이유를 각각 포함할 것","box_id":"requirements"},
      {"style_id":0,"text":"for x in data:","code":true,"box_id":"code_a"},
      {"style_id":0,"text":"    result.append(x)","code":true,"box_id":"code_a"}
    ]
  }
}
```

스타일 ID와 제목 폭의 수치는 문법 예이다. 현재 양식의 실제 값으로 맞춘다. 필요하면 `box_profile: {"path":"확인한 프로필의 절대 경로.xml","sha256":"실제 해시"}`를 body에 넣는다.

`hancom_fill.ps1`은 먼저 한글에서 문단·수식·코드를 작성한다. Python 표준 라이브러리 도구 `wrap_boxes.py`가 저장된 문자·수식이 명세와 정확히 같은지 대조한 다음 원본 상자를 복제하고 문단을 그 안으로 옮긴다. 기존 스타일·폰트를 덮어쓰지 않고 필요한 상자 서식만 가져온다. 그 사본을 다시 한글에서 열어 최종 HWPX·PDF로 저장한다. 중간 파일을 최종본으로 전달하지 않는다.

상자 복제에는 Python 3.10 이상이 필요하며 추가 패키지는 쓰지 않는다. AI 도구가 제공하는 실행 환경이나 이미 설치된 Python을 먼저 확인한다. 명령 별칭이 없으면 `-Python "실제로 확인한 Python 실행 파일의 절대 경로"`를 전달한다. 실행 환경이나 프로그램을 자동 설치하지 않는다. 원본과 기존 결과를 덮어쓰지 않는다.

## 검수

`exam_check.py compare`는 고정 표를 계속 대조하고 명세의 본문 상자만 따로 검사한다. 상자 개수·제목·전체 폭·셀 폭·선·여백이 참고 구조와 맞아야 한다. 내용에 따라 달라지는 높이를 고정 높이로 강제하지 않는다. 문단·수식·코드와 각 상자 안의 소속은 최종 HWPX에서 다시 대조한다. 모든 쪽에서 제목 줄바꿈, 테두리와 글자 사이 간격, 아래쪽 잘림, 다음 문항과의 간격을 확인한다.
