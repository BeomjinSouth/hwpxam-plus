# 검수와 전달

작업 폴더에는 원본 해시, 문항 구성표, 확정 원고, 문항별 검토, 양식 채움 명세, 학생용·교사용 파일과 검수 기록을 둔다. 개인·학교 정보가 있는 자료는 요청 범위 밖으로 보내지 않는다.

## 세 가지 검수를 구분한다

1. **내용 검사**: 모든 문항을 실제로 풀고 모든 보기·서답형 배점을 검토한다. 원고의 조건·자료·질문·선택지·답·해설이 최종 파일에 빠짐없이 들어갔는지 확인한다. 선택지 순서 변경은 번호·답지에 함께 반영한다.
2. **구조 검사**: `exam_check.py check`는 배점·기록·답 연결을 확인한다. `compare`는 원본의 고정 구조·기존 스타일을 비교한다. 이 둘만 통과한 상태는 인쇄 검수 완료가 아니다.
3. **실제 출력 검사**: 해당 HWPX를 한글에서 직접 PDF로 출력한다. 실행 기록에 HWPX와 PDF의 SHA-256·한글 쪽수를 연결한다. 모든 쪽에서 글자·표 잘림, 정렬·간격, 빈 쪽, 머리말·꼬리말, 자동 번호·선택지 줄, 배점 줄바꿈, 서답형 공간을 확인한다.

한글에서 저장·출력을 한 뒤 학생용 문서에 정답·해설·교사 메모·강조 정답·이전 예시 문항·미완성 토큰이 남았는지 다시 확인한다. 교사용에는 정답 선택지 번호와 해설·부분점수 기준이 실제로 인쇄되어야 한다. 원고나 JSON에만 있으면 완료가 아니다.

고정 표의 실제 크기가 바뀌면 실패로 남기고 줄바꿈·문구 길이·채움 위치를 확인한다. 한글 저장 시 표의 집계 높이 캐시만 달라지는 경우에는 `NATIVE_LAYOUT_REVIEW_REQUIRED`(종료 코드 2)를 반환한다. 이는 통과가 아니다. 셀 크기·고정 문구·기존 서식은 같고 집계 높이만 다른지 먼저 확인한 뒤, 실제 한글 PDF에서 원본과 고정 표·셀 테두리의 위치·선폭을 대조한다. 실제 경계가 같다는 증거를 별도 검토 기록에 연결해야 한다. 크기 검사를 끄거나 높이 차이를 모두 무시하지 않는다.

코드 스타일을 추가하면 한글이 내부 글꼴 번호를 재정렬할 수 있다. 비교 도구는 기존 글꼴의 실제 이름·속성과 문단·글자 모양을 대조한다. 숫자 ID가 바뀌었다는 이유만으로 서식 변화를 허용하지 않는다. 기존 글꼴·크기 변화는 실패이며, 명세에 코드가 있을 때만 코드용 글꼴 추가를 허용한다.

발문 아래 상자의 시작점에 원래 본문 빈 줄이 확보되는지 실제 PDF로 본다. 여러 줄 선택지는 번호별 묶음과 순서를 확인한다. 수식은 HWPX의 개수·스크립트와 실제 출력 모양을 함께 확인한다. 코드는 저장된 문자·들여쓰기와 실행 결과를 대조한다. PDF 발췌 그림은 원본 쪽·좌표·해시를 연결하고 축·범례·단위가 남고 다른 문항·해설이 빠졌는지 인쇄 크기에서 확인한다.

검토 기록은 대상 원고와 최종 파일의 해시, 실제 검토한 쪽 번호, 문항별 근거, 미해결 문제, 검토자를 담는다. 검토 전 PASS를 채우지 않는다. 파일이 바뀌면 관련 내용 검사와 출력·해시를 갱신한다. 렌더링이 실패한 파일을 새 PDF 재작성으로 덮지 않는다.

서답형을 검수할 때에는 각 루브릭 요소가 최종 학생용의 어느 발문·조건에 드러나는지 역으로 대조한다. 여러 이유·대상에 각각 점수를 주면 학생용에도 그 구분을 명시해야 한다. 일부 답안의 항목별 점수와 합계도 직접 계산한다. 원고의 `rubric_alignment`와 실제 인쇄된 요구가 달라지면 다시 출력·검수한다.

## 독립 검토용 파일

`python scripts/exam_check.py packet 원고.json 학생용-검토.md`로 답·해설을 뺀 학생용 파일을 만든다. 별도 검토자는 이 파일과 허용 범위만 받아 먼저 답·근거·모호함을 기록하고, 그 뒤 교사용과 대조한다. 본인이 한 자체 재풀이를 독립 검토자로 꾸미지 않는다.

## 교사에게 전달할 상태

학생용 HWPX/PDF, 교사용 정답·해설·채점기준 HWPX/PDF를 분리한다. 완료 보고에는 양식 보존 결과·내용과 인쇄 검수 범위·미확인 사항을 짧게 적는다. 실제 시행 정보·학교 평가계획·교육과정·독립 검토가 남았다면 검토용으로 표시한다. 특정 교과 예시의 통과를 모든 교과·모든 한글 양식의 품질 보증으로 확대하지 않는다.

교사용은 학생용 표지·응시 안내가 남지 않고 실제 문항 번호별 정답·해설·예시 답안·채점기준이 구분되는지 확인한다. 조건·코드 상자는 [전용 기준](해설-조건상자와-코드.md)대로 검사한다. 제작 메모·검증 상태·PDF 발췌 안내는 별도 기록으로 분리한다.
